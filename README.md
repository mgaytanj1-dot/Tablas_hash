En c++ se implementó manualmente una tabla hash utilizando
separate chaining mediante listas enlazadas, lo que permite
comprender el funcionamiento interno de una estructura hash,
incluyendo manejo de colisiones y cálculo de buckets.

En cambio en java se utilizó hashmap, una estructura nativa del lenguaje
que abstrae automáticamente la gestión de colisiones y el
almacenamiento interno, permitiendo una implementación más
simple y rápida.
